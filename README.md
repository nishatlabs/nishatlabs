## 🛡️ I protect it

Then I fix what I found and harden the system so it stays secure.

- HTTPS, TLS config & security headers (HSTS, CSP, X-Frame-Options)
- Secure cookies — Secure, HttpOnly, SameSite
- Email security — SPF, DMARC, DNSSEC, CAA
- WordPress & CMS hardening
- Malware, backdoor & web shell removal
- Web server & cPanel security
- Exposed files (.git, .env), open ports & outdated CVEs
- Clear reports with severity, fixes and retest

> 🔒 Every test runs inside an agreed scope with written permission. Bug bounty work stays inside each program's rules.

## 🚀 Featured project

### 🔐 AuditPulse — website security tester  `🟠 Launching soon`

Enter a domain and AuditPulse runs **14 categories of checks**, then explains each finding and how to fix it. Read-only: it looks only at public information and never attacks or changes a site.

| Checks | |
|---|---|
| 🔒 HTTPS, certificates & old TLS | 🧾 Security headers & cookie flags |
| 📧 SPF, DMARC, DNSSEC | 📂 Exposed `.git`, `.env`, backups |
| 🔌 Open database ports | 📦 Outdated libraries + known CVEs |
| 🧩 WordPress versions & plugins | 🌐 Forgotten & dangling subdomains |
| 🚫 Blacklist & Safe Browsing | ⏳ Domain expiry & HSTS preload |

**Also:** lookalike-domain detection · daily monitoring & alerts · white-label PDF reports

`Next.js` `React` `TypeScript` `Tailwind CSS` `SQLite` `Docker` `Railway`
